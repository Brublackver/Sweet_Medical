Ramas:

main — código base inicial del proyecto Carpeta backend

Entrega-1 — primera versión con las funcionalidades básicas (CRUD médicos, disponibilidad, turnos)

Entrega-1-v2 — evolución de Entrega-1, donde se agregaron mejoras, más funcionalidades y los tests unitarios

Entrega-2-v1 — segunda entrega con persistencia en MongoDB, cobertura de obra social, notificaciones, Swagger, y conexión a MongoDB Atlas

El flujo fue:

main ← Entrega-1 ← Entrega-1-v2 ← Entrega-2-v1

Arrancamos desde main
Creamos Entrega-1 para desarrollar el MVP
Creamos Entrega-1-v2 para agregar funcionalidades faltantes y los 2 tests unitarios
Creamos Entrega-2-v1 para la segunda entrega: persistencia NoSQL, cálculo de cobertura por plan del paciente, agrupado de turnos por día, filtro de historial por fecha, turnos confirmados del médico, documentación Swagger y base de datos en la nube con MongoDB Atlas
